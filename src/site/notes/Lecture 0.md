# 1. What is Agentic AI?

Agentic AI is an AI system that can perform tasks with minimal human guidance. Instead of only answering questions, it can:

- Understand goals
    
- Plan multiple steps
    
- Use tools
    
- Make decisions
    
- Complete tasks automatically
- ![Pasted image 20260801200200.png](/img/user/Pasted%20image%2020260801200200.png)
    

Examples:

- Research assistant
    
- AI coding assistant
    
- AI customer support agent
    
- AI workflow automation
    

---

# 2. Why We Need a Knowledge Base

An AI agent performs better when information is organized.

Instead of storing notes in many places, we create a central knowledge base where:

- Notes are connected.
    
- Information is easy to search.
    
- AI can understand relationships between topics.
    

---

# 3. Installing Obsidian

Obsidian is a note-taking application based on Markdown files.

### Steps

1. Download Obsidian.
    
2. Install the software.
    
3. Create a new Vault.
    
4. Give the vault a name.
    
5. Start creating notes.
    

Each note is saved as a Markdown (.md) file.

---

# 4. Organizing Notes in Obsidian

Create folders such as:

- AI Basics
    
- Agentic AI
    
- Prompt Engineering
    
- Projects
    
- Research Papers
    

Use:

- Headings
    
- Bullet points
    
- Tags
    
- Internal links
    

Example:

```
[[Prompt Engineering]]
```

This links one note to another.

# 5. Using Obsidian AI

Obsidian AI helps in:

- Summarizing notes
    
- Explaining concepts
    
- Improving writing
    
- Generating ideas
    
- Answering questions from your notes

Benefits:

- Saves time
    
- Improves understanding
    
- Makes note-taking smarter

# 6. What is a Digital Garden?

A Digital Garden is an online collection of your personal notes.

Unlike a blog:

- Notes continue to grow.
    
- You can update them anytime.
    
- Information stays connected.
    

Think of it as a personal knowledge website.

---

# 7. Why Create a Digital Garden?

Benefits:

- Share learning publicly
    
- Build a portfolio
    
- Organize research
    
- Access notes from anywhere
    
- Demonstrate your AI knowledge

# 10. Deploying with Vercel

Vercel is a cloud platform used to host websites.

In this lecture, Vercel was used to publish the Digital Garden.

![Pasted image 20260801195452.png](/img/user/Pasted%20image%2020260801195452.png)

### Steps

1. Create a Vercel account.
    
2. Connect your GitHub account.
    
3. Import the GitHub repository.
    
4. Select the project.
    
5. Click Deploy.
    
6. Wait for deployment.
    
7. Receive a live website URL.
    

Whenever GitHub is updated, Vercel automatically updates the website.

# 12. API Token

An API Token is a secret key that allows software to communicate securely with AI services.

It acts like a password.

Never share your API token publicly.

![Pasted image 20260801195932.png](/img/user/Pasted%20image%2020260801195932.png)


---

# 13. Downloading an API Token

General steps:

1. Create an account with the AI service.
    
2. Open the developer or API dashboard.
    
3. Generate a new API token.
    
4. Copy the token.
    
5. Store it securely.
    
6. Use it in your application or plugin.
    

---

# 14. Why is the API Token Needed?

The token allows applications to:

- Access AI models
    
- Generate responses
    
- Summarize notes
    
- Answer questions
    
- Perform AI-powered tasks
    

Without a valid token, the application cannot access the AI service.

---

# 15. Security Best Practices

- Never share your API token.
    
- Do not upload it to GitHub.
    
- Store it in environment variables or configuration files.
    
- Regenerate it immediately if it is exposed.
